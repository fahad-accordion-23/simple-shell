# Simple Shell

Simple shell implementation. 

- Checkout the tutorial I followed: [Tutorial - Write a Shell in C, Stephen Brennan](https://brennan.io/2015/01/16/write-a-shell-in-c/).
- Also see Stephen's implementation (GitHub repository): [lsh](https://github.com/brenns10/lsh).

## Running

Just run `make` and execute `main`.
